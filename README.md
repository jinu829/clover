# FaceBuilder: 사진으로 3D 얼굴 만들기

정면 사진(+ 측면 사진)을 넣으면 3D 얼굴 파일(`face.obj`)과
웹브라우저로 돌려볼 수 있는 뷰어(`viewer.html`)를 만들어 줍니다.

---

## 1. 파이썬 설치 (처음 한 번만)

이미 설치되어 있으면 이 단계는 건너뛰세요.
(확인 방법: 시작 메뉴에서 "명령 프롬프트"를 열고 `python --version` 입력. `Python 3.x.x`가 나오면 설치된 상태입니다.)

1. https://www.python.org/downloads/ 에서 **Download Python** 버튼을 누릅니다.
2. 받은 설치 파일을 실행합니다.
3. **아주 중요:** 첫 화면 아래쪽의 **"Add python.exe to PATH"** 에 체크합니다.
4. **Install Now** 를 누릅니다.

## 2. 프로그램 설치 (처음 한 번만)

1. 이 `facebuilder` 폴더를 원하는 곳에 둡니다. 예: `C:\facebuilder`
   - 경로가 짧을수록 좋습니다. 경로가 너무 길면 설치 중에 오류가 날 수 있습니다.
2. 폴더 안의 **`setup.bat`** 을 더블클릭합니다.
3. 검은 창에 설치 과정이 표시됩니다. "설치 완료!"가 나올 때까지 기다리세요(몇 분 걸립니다).

## 3. 실행하기

### 방법 A: 더블클릭 (추천)
1. **`run.bat`** 을 더블클릭합니다.
2. 안내 창이 뜨면 **정면 사진**을 고릅니다.
3. 이어서 **측면 사진**을 고릅니다(Ctrl을 누른 채 여러 장 선택 가능, 없으면 "취소").
4. 잠시 뒤 웹브라우저에 3D 얼굴이 뜹니다.
   - 처음 실행할 때는 얼굴 인식 모델(약 4MB)을 자동으로 내려받으므로 인터넷 연결이 필요합니다.

### 방법 B: 명령어로 실행
`facebuilder` 폴더에서 주소창에 `cmd` 를 입력하고 Enter를 누르면 그 위치에서 명령 프롬프트가 열립니다.

```
.venv\Scripts\activate
python main.py --front 사진\정면.jpg --side 사진\왼쪽.jpg 사진\오른쪽.jpg
```

| 옵션 | 뜻 |
|---|---|
| `--front 파일` | 정면 사진 (필수, 생략하면 선택 창이 뜸) |
| `--side 파일 파일 ...` | 측면 사진들 (선택) |
| `--engine mediapipe` / `keentools` | 사용할 엔진 (기본: mediapipe) |
| `--out 폴더` | 결과 저장 폴더 (기본: `output`) |
| `--no-open` | 끝난 뒤 뷰어를 자동으로 열지 않음 |

## 4. 결과물

`output\날짜_시간\` 폴더에 저장됩니다.

| 파일 | 설명 |
|---|---|
| `viewer.html` | 더블클릭하면 브라우저에서 3D 얼굴을 돌려볼 수 있음 (인터넷 필요) |
| `face.obj`, `face.mtl`, `texture.jpg` | 표준 3D 파일. Blender나 Windows "3D 뷰어"에서 열 수 있음 (세 파일을 같은 폴더에 둘 것) |

뷰어 조작: 왼쪽 드래그는 회전, 휠은 확대/축소, 오른쪽 드래그는 이동, `T` 키는 사진 입히기 켜기/끄기, `W` 키는 와이어프레임 보기입니다.

## 5. 좋은 사진 찍는 법

- 얼굴이 사진의 큰 부분을 차지하도록 찍기
- 밝고 고른 조명, 그림자가 적게
- 정면 사진에서는 카메라를 똑바로 보고, 앞머리나 안경이 얼굴을 가리지 않게
- 측면 사진은 왼쪽, 오른쪽으로 각각 30~60도 돌린 사진 (완전한 옆모습 90도는 인식 안 됨)
- 모든 사진은 같은 조명, 같은 표정(무표정 추천)으로

## 6. 자주 나는 오류

| 메시지 | 해결 |
|---|---|
| `'python'은(는) ... 아닙니다` | 1단계에서 "Add python.exe to PATH" 체크를 빠뜨렸습니다. 파이썬을 다시 설치하세요. |
| `먼저 setup.bat 을 ...` | `setup.bat` 을 먼저 실행하세요. |
| `정면 사진에서 얼굴을 찾지 못했습니다` | 얼굴이 더 크고 밝게 나온 정면 사진을 쓰세요. |
| `모델 다운로드에 실패했습니다` | 인터넷 연결을 확인하세요. |
| `KeenTools 엔진은 아직 연결되지 않았습니다` | 아래 7번을 보세요. 지금은 기본 엔진을 쓰세요. |

## 7. 구조와 KeenTools 연결

```
facebuilder/
├─ main.py                     실행 시작점 (사진 받기 → 엔진 실행 → 저장 → 뷰어 열기)
├─ setup.bat / run.bat         설치 / 실행용 더블클릭 파일
├─ requirements.txt            설치할 라이브러리 목록
└─ facebuilder/
   ├─ picker.py                사진 선택 창
   ├─ geometry.py              사진 정렬, 얼굴 모양 합치기, 머리 전체 모양 만들기
   ├─ texture.py               여러 사진으로 머리 전체 텍스처 만들기
   ├─ exporter.py              OBJ 파일과 뷰어 HTML 저장
   └─ engines/
      ├─ base.py               모든 엔진이 지키는 약속 (FaceMesh)
      ├─ mediapipe_engine.py   지금 동작하는 기본 엔진
      └─ keentools_engine.py   KeenTools 를 연결할 자리 (TODO)
```

엔진은 "사진을 받아서 FaceMesh(점, 삼각형, 텍스처)를 돌려주는 부품"입니다.
KeenTools를 연결할 때는 `keentools_engine.py` 의 `build()` 만 채우면 되고,
나머지 코드는 그대로 둡니다. 다 채운 뒤에는 이렇게 실행합니다:

```
python main.py --front 정면.jpg --side 측면.jpg --engine keentools
```

## 8. 기본 엔진(MediaPipe)이 하는 일과 한계

1. 모든 사진에서 얼굴 점 468개를 찾고, 측면 사진이 몇 도 돌아가 있는지 계산합니다.
2. 얼굴 각 부분을 가장 잘 본 사진 위주로 얼굴 모양을 합칩니다(볼 옆면은 측면 사진이 더 반영됨).
3. 얼굴 테두리를 두개골 모양(타원체)과 이어서 닫힌 머리를 만듭니다.
4. 모든 사진에서 색을 가져와 머리 전체 텍스처를 만듭니다. 어느 사진에도 안 보인 곳은
   좌우 반대편 색이나 주변 색으로 채웁니다.

한계
- **완전한 옆모습(90도) 사진은 인식되지 않아 건너뜁니다.** 측면 사진은 30~60도 돌린 것을 쓰세요.
  실행 화면에 사진마다 "고개 방향 약 +40도"처럼 표시되니 확인할 수 있습니다.
- 뒤통수 모양은 일반적인 머리 비율로 추정합니다. 귀, 머리카락의 입체 모양은 만들지 않습니다.
- 더 정밀한 머리(귀 포함, 실제 머리 모양)는 KeenTools 엔진이 맡을 부분입니다.
